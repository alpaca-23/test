以下の手順で README を更新してください。

1. カレントディレクトリのプロジェクト名を確認する（フォルダ名を使用）
2. そのプロジェクトの `README.md` を、コード・設定・機能の現状に合わせて更新する
   - 配信ソース、動作仕様、セットアップ手順、設定項目などを最新状態に反映する
3. 更新した `README.md` の内容を `../md/{プロジェクト名}_README.md` にも書き込む（新規作成 or 上書き）
4. 変更した2ファイルを git に add してコミットする（メッセージ: `docs: README を更新`）

必ずファイルの現状を Read してから編集してください。
